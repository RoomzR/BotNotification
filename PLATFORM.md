# CyberX Control / BotNotification

Платформа мониторинга клуба **CyberX Gomel, Интернациональная 13**: камеры Hikvision + Telegram + склад/операции (Langame stub).

## Что умеет

| # | Модуль | Как работает сейчас |
|---|--------|---------------------|
| 1 | Все камеры: своя еда/напитки, чистота, нарушения | YOLO по RTSP, алерты в Telegram |
| 2 | Холодильник / витрина | Оценка заполненности по кадру |
| 3 | Накладные → товары | `/invoice` в боте → локальный склад (+ HTTP Langame когда дадите API) |
| 4 | Температура зон | `/temp зал 23.5`, пороги в `platform.yaml` |
| 5 | Внештатные ситуации | толпа, лежащий человек, тесный контакт |
| 6 | Телефон / геймпады | `/phone`, `/pad` |
| 7 | Бонусы | `/bonus` + `/approve` (подтверждение собственника) |
| 8 | Техрежим / блок ПК | `/pc PC12 block` (нужен agent URL для реального действия) |
| 9 | Работа с гостями | `/guest`, `/guests` |
| 10 | Списание/начисление | `/adjust` |
| 11 | Состояние сотрудника | детекция присутствия в зоне |
| 12 | Задачи руководителя | `/task`, `/tasks`, `/done` + напоминания о просрочке |

Правила клуба (в т.ч. **нельзя со своей едой/напитками**) — `/rules`.

> Детектор «своей» продукции даёт **подозрение** (бутылка/стакан/еда у гостя). Отличить «куплено в баре CyberX» от «принесли с собой» на 100% по камере нельзя без доп. обучения/интеграции с продажами бара.

## Desktop для сотрудника

```bat
run_desktop.bat
```

или:

```bat
.venv\Scripts\python.exe run_desktop.py
```

Вкладки:
1. **Как работать** — инструкция для сотрудника (CyberX стиль)
2. **Камеры** — мозаика + детекторы
3. **Контроль** — очередь и «со своим»
4. **Каталог** — SKU, эталоны, **ЭКСПОРТ / ИМПОРТ ZIP**
5. **Алерты** — история (+ Telegram)

### Скан без сканера на ПК клуба

На ноутбуке:
1. Каталог → фото (веб-камера или файл с телефона)
2. «Сохранить эталон (OCR)»
3. **ЭКСПОРТ ZIP** → файл `cyberx_catalog_pack_….zip`
4. Отправить в Telegram / флешку

На ПК клуба:
1. Скачать ZIP
2. Каталог → **ИМПОРТ ZIP**

Каталог сидится из `data/bar_catalog.yaml`.

Доп. модели (опционально):

```bat
.venv\Scripts\python.exe scripts\download_models.py
```

Скачиваются в `models/`:
- `brandeye.pt` — brand/logo YOLO (частичное пересечение с Coca/Fanta/…)
- `retail_product.pt` — детектор упаковок (класс `product`)

Готовой модели именно под TUC/Хрустим/Бульба/Gorilla в открытом доступе нет — основной путь OCR + каталог.

Сборка exe (Windows):

```bat
build_desktop.bat
```

## Запуск (старый способ — только мозаика OpenCV)

```bat
cd D:\BotNotification
.venv\Scripts\activate.bat
run_platform.bat
```

или:

```bat
.venv\Scripts\python.exe run_platform.py
```

Откроется **экран-мозаика** камер: текущая проверка, своя еда, чистота, витрина.
На Reception — рамка **ADMIN QUEUE ROI** (очередь у админки, 25с из `config.yaml`).

- `Q` — выход  
- `Пробел` — пауза  

В Telegram: `/help`  
ROI очереди: `setup_roi.bat`  
Только Reception без платформы: `run.bat`

## Настройка

- `.env` — токен бота, chat_id, пароль NVR
- `platform.yaml` — список камер, модули, пороги температуры
- `config.yaml` — ROI очереди у Reception (из `setup_roi.bat`)

### Подключить реальный Langame

В `platform.yaml`:

```yaml
langame:
  mode: http
  base_url: "https://your-langame-api"
  api_token: "..."
  pc_agent_url: "http://192.168.x.x:8787"
```

Пока `mode: stub` — всё пишется в `data/cyberx.db`.

## Важно

- Не запускай одновременно `run.bat` и `run_platform.bat` (один бот-токен).
- На слабом ПК уменьши список `cameras` в `platform.yaml` или `cameras_per_cycle: 1`.
